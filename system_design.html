Diseño de Sistemas

estado: en progreso (ver pendientes)

El diseño de sistemas es el proceso de definir la arquitectura, componentes y relaciones de un sistema para hacerlo robusto y confiable.

Disponibilidad y Escalabilidad

La disponibilidad y la escalabilidad son aspectos clave del diseño de sistemas. Garantizan que el sistema pueda manejar un gran número de usuarios y solicitudes sin interrupciones.

  • Escalabilidad: La capacidad de manejar un volumen creciente de datos o tráfico.
    • Escalabilidad horizontal: Agregar más servidores o nodos.
    • Escalabilidad vertical: Agregar más recursos a un servidor existente.
  • Disponibilidad: La proporción de tiempo que un sistema permanece operacional y responsivo ante las solicitudes.
    • disponibilidad = tiempo_disponible tiempo_real

¿Cómo manejar la escalabilidad horizontal?

Un Balanceador de Carga (Load Balancer) distribuye las solicitudes entre los servidores utilizando diferentes algoritmos, tales como:

  • Round Robin: Distribuye las solicitudes secuencialmente, sin importar la carga del servidor.
  • Least Connections (Menos Conexiones): Dirige las solicitudes al servidor con menos conexiones activas, útil para manejar cargas de trabajo variables.

Bases de Datos

Para almacenar los datos de usuario, dependemos de almacenamiento físico o en la nube, donde los datos pueden estructurarse en diferentes formatos:

  • SQL: Los datos se estructuran en tablas relacionales y las transacciones siguen los principios ACID.
  • NoSQL: Modelos de datos flexibles, optimizados para escalabilidad horizontal y diversos tipos de datos.

¿Qué es ACID?

  • Atomicidad: Garantiza que todas las operaciones dentro de una transacción se completen totalmente o fallen por completo.
  • Consistencia: Asegura que la base de datos permanezca en un estado válido antes y después de cualquier transacción.
  • Aislamiento (Isolation): Asegura que las transacciones concurrentes se ejecuten de forma independiente sin interferir entre sí.
  • Durability (Durabilidad): Garantiza que los datos de transacciones confirmadas se guarden permanentemente, incluso en caso de un fallo del sistema.
